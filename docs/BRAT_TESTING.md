# BRAT実地検証ガイド（0.10.0-beta.1）

## 先に確認すること

BRATが配布するのはObsidianプラグインの `main.js`、`manifest.json`、`styles.css` だけです。
Whisper認識サーバーと辞書ファイルはPC側に残るため、このリポジトリの同じリリース／コミットへ
サーバー側も更新してから起動してください。旧サーバーへ新プラグインをつなぐと辞書一覧と1件登録APIは使えません。

```powershell
git fetch origin --tags
git switch codex/dictionary-phase2
git pull
cd server
.\run.ps1
```

## BRATから入れる

1. ObsidianでBRATをインストールして有効化する。
2. コマンド「BRAT: Add a beta plugin for testing」を実行する。
3. `surblue-git/voxcraft` を追加する。
4. VoxCraftのリリース選択が可能な場合は `0.10.0-beta.1` を選ぶ。
5. コミュニティプラグインでVoxCraftを有効化／再読み込みする。

プライベートリポジトリの場合はBRATに読み取り可能なGitHub tokenが必要です。

## 最少実用版の確認項目

- 設定 → VoxCraft → ユーザー辞書に、各接続先の「使用する辞書」が表示される。
- コマンド「辞書セットを選択」でセットを変更でき、次回開いたときも保持される。
- 録音を開始するとステータスバーに `辞書: 共通` のように実際のセット名が出る。
- その録音で、登録済み置換が文字起こし結果へ適用される。
- ノート上の誤認識を2文字以上選択し、「選択範囲を辞書に追加」で正しい表記を登録できる。
- 同じ登録を繰り返しても重複せず、「すでに同じ登録」と案内される。
- 同じ誤認識に異なる正解を登録しようとすると上書きされず、競合として案内される。
- 登録後に新しく録音を開始すると置換が反映される（進行中セッションは固定されたまま）。
- 再変換と「音声から再認識」も、選択した辞書セットを返す。
- PCとAndroid/Tailscaleの接続先で、別々のセット選択が保持される。

登録後、PC側では `server/dictionaries/profiles/<id>.json` と直前バックアップ
`<id>.json.bak` を確認できます。問題があればサーバーログ、Obsidian開発者コンソール、
再現した操作、選択セットIDを記録してください。

## ロールバック

Obsidian側はBRATで `0.9.7` へ戻します。辞書データは新形式が正規ですが、1件登録直前の内容は
`.json.bak` に残ります。サーバーを止め、必要な場合だけ本体JSONを別名退避してからバックアップを戻してください。
